# Money Dashboard

A responsive personal finance dashboard designed to display and manage monthly financial information in a clean and organized interface.

## 📌 About The Project

Money Dashboard is a static dashboard UI created to represent a personal monthly finance management system for a user named Seif Osama.

The dashboard provides a clear overview of the user's current balance, income, expenses, recent transactions, activities, and available financial actions.

The main goal of this project was to practice building a complete dashboard layout using HTML and CSS while creating a responsive design that works across different screen sizes.

## ✨ Features

- Clean and modern dashboard interface
- Monthly financial overview
- Current balance, income, and expenses sections
- Recent transactions section
- Recent activities section
- Quick financial actions
- Responsive layout for different screen sizes
- Arabic user interface
- Structured and organized page layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Grid
- CSS Media Queries
- Google Fonts
- Font Awesome

## 📱 Responsive Design

The dashboard is designed to provide a consistent user experience across desktop, tablet, and mobile screen sizes.

CSS Media Queries were used to adapt the layout and components to different viewport sizes.

## 🎯 Project Goals

This project was built to:

- Practice creating real-world dashboard interfaces.
- Improve HTML page structure and organization.
- Develop responsive layouts using CSS.
- Gain practical experience with CSS Grid.
- Improve attention to spacing, alignment, typography, and visual hierarchy.
